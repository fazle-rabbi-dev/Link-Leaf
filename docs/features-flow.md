## Profile Management

> Public profile page accessible via `/domain/<username>`

## Dashboard Pages

> **Real-time preview of profile:** is availabele on entire dashboard for all pages

### Profile Page

- Profile customization (name, username, bio, avatar upload)
- Publish/unpublish profile by clicking on the publish/unpublish button

### Links Page

- **Social Links:** Predefined platforms (Instagram, GitHub, Twitter, etc.)
- **Custom Links:** User-defined label + URL pairs with optional icons
   - Icon upload for custom links
- Toggle active/inactive status
- Allows links crud operations
   - Add/edit/delete from modal
